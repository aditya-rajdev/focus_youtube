# 🎯 YouTube Focus Mode

**Stop getting distracted on YouTube.** Transform YouTube into a clean, focused, and intentional tool for learning, working, and studying.

---

## 💡 What is YouTube Focus Mode?

Do you open YouTube to watch a specific video and end up wasting hours scrolling through recommended videos and Shorts? 

**YouTube Focus Mode** fixes that! It removes addicting recommendations, infinite Shorts reels, up-next video sidebars, and distracting comments so you can watch what you came for without losing time.

---

## ✨ Main Features

- 🏠 **Blank Homepage**: No recommendation feed when you open YouTube—just a clean, simple search bar.
- 🚫 **No Shorts**: Blocks YouTube Shorts everywhere so you don't get trapped in infinite scrolling loops.
- 🔍 **Clean Search Results**: Shows only genuine search results—removes sponsored ads and unrelated algorithm carousels.
- 🎬 **Distraction-Free Video Watching**:
  - Hides the "Up Next" / recommended videos sidebar.
  - Automatically turns off Autoplay (stops next video from playing automatically).
  - Keeps all standard video controls (speed, quality, captions, theater mode, fullscreen).
- 🔒 **Complete Block Mode (Strict Mode)**:
  - Only lets you watch videos you deliberately searched for.
  - Pauses and blocks direct video links opened from outside YouTube.
  - Shows a *"Video completed"* screen when your video ends.
- 🛡️ **100% Safe & Private**: Runs entirely inside your browser. Zero tracking, no data collection, no external servers.

## 🛠️ How to Install in Google Chrome (or Edge / Brave / Arc)

It takes less than 1 minute to install:

1. **Download / Clone** this repository to your computer.
2. Open your browser and type `chrome://extensions` in the address bar.
3. Turn ON **Developer mode** using the toggle in the top-right corner.
4. Click the **Load unpacked** button in the top-left corner.
5. Select the `youtube_extenstion` project folder.
6. 🎉 **Done!** Click the Extension (puzzle piece) icon in your browser toolbar and pin **YouTube Focus Mode** for quick access.

---

## ⚙️ How to Use

1. Click the **YouTube Focus Mode** icon in your browser toolbar.
2. Easily turn features ON or OFF:
   - Turn **Complete Block Mode** ON when studying or working for maximum focus.
   - Customize individual settings (hide Shorts, hide sidebar, hide comments, etc.).
3. Enjoy a calm, distraction-free YouTube experience!
